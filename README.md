# 자링고비

> 혼자 참는 절약에서, 함께 완주하는 한 주로.

자링고비는 친구·연인·동료와 한 방에 모여 주당 기준금액을 정하고, 사진으로 지출을 기록하며 서로 응원하는 소셜 지출 앱입니다.

대한민국 공휴일과 합류 시점을 반영해 사람마다 실제로 지켜야 할 한도를 자동으로 계산합니다. 주 중간에 합류해도 남은 유효 평일만큼 공정하게 도전할 수 있습니다.

## 이런 경험을 만듭니다

- **함께 시작하기** — 6자리 코드로 비공개 방에 초대하고 참여합니다.
- **공정한 한도 계산** — 공휴일과 중도 합류일을 반영해 개인별 적용 한도를 계산합니다.
- **사진으로 지출 기록하기** — 지출마다 사진을 남기고 그 지출에서 바로 대화합니다.
- **예외를 함께 정하기** — 어쩔 수 없던 지출은 예외를 요청하고, 멤버가 모두 승인하면 정산에서 뺍니다.
- **가볍게 경쟁하기** — 남은 금액이 가장 큰 참여자에게 왕관을 표시합니다.
- **한 주씩 정리하기** — 주가 끝나면 보완·정산 시간을 거쳐 결과를 읽기 전용 기록으로 보관합니다.

## 핵심 정책

- 한 기간은 월요일부터 금요일까지의 한 주로 고정됩니다.
- 방 생성 후 주당 기준금액은 변경할 수 없습니다.
- 대한민국 공휴일은 유효 평일과 적용 한도에서 제외합니다.
- 진행 중 합류자는 합류일부터 남은 유효 평일만 적용합니다.
- 금요일이 끝나고 12시간 동안 누락 지출을 보완하고, 이후 36시간 동안 결과를 정산합니다. 정산이 끝나는 시점이 곧 다음 주가 열리는 월요일 0시입니다.
- 한 번에 한 방에만 참여하며, 나간 방에는 다시 들어올 수 없습니다.
- 수입은 기록하지 않으며 사용자가 직접 등록한 지출만 집계합니다.

## 현재 구현 범위

- 이메일 회원가입·로그인·비밀번호 재설정·계정 탈퇴
- 방 생성·참여·초대 코드·방 이동
- 개인별 적용 한도와 진행률
- 지출 기록과 사진 첨부, 지출별 댓글과 1단계 답글
- 지출 예외 요청과 멤버 승인
- 방 안 커뮤니티 게시글·댓글·반응·투표
- 앱 안 소식함 (기기 알림은 보내지 않습니다)
- 오프라인 변경 큐와 재동기화
- 지난 기간 기록 열람

## 기술 구성

Expo 57 · React Native · TypeScript · Expo Router · Supabase · AsyncStorage

## 개발

```bash
npm install
npm start          # Expo 개발 서버
npm run qa         # 타입체크 + 린트 + 단위 테스트
npm run native:reset  # 재생성 산출물 정리 후 네이티브 프로젝트 재생성
```

Supabase 연결 정보가 필요합니다. `.env.example`을 참고해 `.env`를 만드세요.
